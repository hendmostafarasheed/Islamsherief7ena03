GITHUB PAGES — HENNA INVITATION (FLAT FILES)

Upload these files directly into the root of your repository:
- index.html
- invitation-cover.png
- invitation-details.png
- background-music.mp3

Interactive actions:
- Open Invitation: switches to page 2 and attempts music playback.
- Location: opens Google Maps search for Hilton Hotel Ballroom (A).
- Confirm Attendance: asks for the host WhatsApp number and guest name, then opens WhatsApp with a prepared RSVP.
- Share: opens native sharing where supported, or offers the URL to copy/select.
- Photos: shows the two invitation images and lets the visitor enter a public photo album URL.

Note: For an exact venue pin, change MAPS_QUERY in index.html to the venue's full address. Upload over the existing index.html and image files, then wait for GitHub Pages to redeploy. If an old version remains visible, refresh in an incognito tab.
